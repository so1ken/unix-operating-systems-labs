# Лабораторная работа №3: Жёсткие ссылки (Hard Links)

## Описание
Консольное приложение на C++, которое рекурсивно обходит указанный каталог, вычисляет SHA-1 хэш каждого файла и заменяет дубликаты на жёсткие ссылки, указывающие на первый найденный экземпляр.

## Зависимости
Для сборки необходима библиотека OpenSSL (API EVP):
```bash
sudo apt install libssl-dev
```

## Сборка
Соберите проект с помощью компилятора g++:
```bash
g++ -Wall -Wextra -std=c++17 -O2 lab3.cpp -o dedup -lcrypto
```

## Тестирование
1. Подготовка данных
Запустите скрипт, который создаст папку test_dir с тестовыми файлами (три дубликата и один уникальный):
```bash
./run_test.sh
```

2. Запуск программы
Передайте папку в качестве аргумента:
```bash
./dedup test_dir
```

3. Проверка результатов
Убедитесь, что дубликаты теперь ссылаются на один и тот же inode и имеют 3 жёсткие ссылки:
```bash
ls -li test_dir
```

# Ожидаемый вывод:
Файлы file1.txt, file2.txt и file3.txt должны иметь одинаковый inode и число ссылок 3. У unique.txt будет свой inode и число ссылок 1.
